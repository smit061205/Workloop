# Workloop Studios

A software studio from India. We build websites, apps, AI tools and automation for
startups and small businesses, with every running cost shown in rupees.

## What's here

- `website/`: the studio website (Next.js 16, Tailwind CSS v4, Lenis smooth scroll).
  All the words are in `website/src/content/site.ts`.
- `docs/design-spec-arcticbase.md`: the layout and type measurements the site follows.
- `CLAUDE.md`: standing notes for working on this repo with Claude Code.

## Run the website

```bash
npm --prefix website install
npm --prefix website run dev
```

Then open http://localhost:3000.
